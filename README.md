# Тест по автоматизации

Интерактивный тест по материалам исходного документа.

## Структура

- `index.html` — готовый сайт, полностью автономный, без внешних зависимостей.

## Возможности

- 12 вариантов;
- 20 вопросов в каждом варианте;
- всего 240 вопросов;
- выбор варианта кнопками;
- перемешивание позиций ответов;
- проверка результата;
- работает без сервера и внешних библиотек.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Нажмите **Save**.
7. Через некоторое время GitHub Pages выдаст адрес сайта.
